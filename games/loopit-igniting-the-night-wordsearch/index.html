Igniting the Night guide

Igniting the Night is the DECADANCE wordsearch on Loopit. Our run verified the loading shell and the playable board with ten visible facility names above the grid.

Last updated July 19, 2026 · 1 tracked update

Play source game
Quick answer

Wait for the board to load, then use the target list above the grid to trace each facility word in the puzzle. The verified board lists ten targets, including POOLTABLE, SAUNA, JACUZZI, and BAR.

How to play

  • The page starts with a loading shell before the puzzle board appears.
  • The board shows ten hidden DECADANCE facility names above the grid.
  • The grid fills the center of the card once loading completes.
  • We verified the playable board, not a full solve.

Controls

  • Wait for the board to render before trying to solve anything.
  • Use the top list to choose a target word.
  • Trace the matching letters through the grid in the usual wordsearch style.
  • Treat the loading shell as pre-play, not as a puzzle state.

Strategy tips

  • Start with the longer targets so you can orient yourself faster.
  • Keep the target list visible while you scan the grid.
  • Do not assume the board is solved just because the card loaded.

Common mistakes

  • Counting the loading screen as progress.
  • Ignoring the target list above the grid.
  • Trying to read the grid before it has fully rendered.
