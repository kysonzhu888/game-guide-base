Quick answer

Open Practice / Make Level, draw a path, and use the retry flow if the shot misses. The verified run ended in the Missed! state, so the campaign path remains pending.

How to play

  • The menu shows Shop, Rankings, and Practice / Make Level.
  • Practice mode adds Draw Path, Add Obstacle, Clear Field, and Back to Campaign.
  • The verified path drew one shot line and landed on Missed! Tap to retry.
  • The campaign progression was not advanced in this run.

Controls

  • Use Practice / Make Level to enter the drawing flow.
  • Drag to draw a shot path toward the goal.
  • Use Back to Campaign, Add Obstacle, or Clear Field as needed.

Strategy tips

  • Start in Practice so you can redraw quickly after misses.
  • Draw a simple straight line first to learn the shot behavior.
  • Clear the field before retrying if your previous path makes the layout hard to read.

Common mistakes

  • Treating the first drawn line as guaranteed success.
  • Forgetting to use the retry prompt after a miss.
  • Confusing Practice / Make Level with campaign advancement.
