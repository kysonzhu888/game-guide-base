W Game guide

W Game is a colorful Loopit fluid sandbox. Web replay reached the playable particle field and verified the on-screen Drag to Fluid prompt.

Last updated July 2, 2026

Play source game
Quick answer

Drag across the particle field to create fluid motion. This replay verified the start state and prompt, but did not identify a score or clear condition.

How to play

  • The screen is filled with small colored particles on a black background.
  • The visible instruction says Drag to Fluid.
  • There is no score, timer, or win counter visible in the captured start state.
  • Treat it as a sandbox interaction unless a later result state appears.

Controls

  • Drag through the particle area to stir or move the fluid field.
  • Use longer swipes for larger motion and shorter swipes for local changes.
  • Do not expect taps alone to show meaningful progress.

Strategy tips

  • Start with a slow horizontal drag so you can see how particles respond.
  • Then try circular movement if the field needs stronger motion.
  • Because no goal counter is visible, describe the interaction rather than claiming a clear.
  • For future replay, record video and compare particle motion frame by frame.

Common mistakes

  • Using taps instead of drag gestures.
  • Looking for a passcode or level counter that is not visible in the replay.
  • Calling it completed without a result screen.
