wave guide

Wave opens directly to a CRASHED screen with score 0. In our verified sample, tapping retry did not visibly recover the game.

Last updated July 21, 2026 · 1 tracked update

Play source game
Quick answer

There is no successful play branch in the verified browser sample; the share page opens crashed and the retry tap leaves it crashed.

How to play

  • The share page opens on a CRASHED state with score 0.
  • TAP TO RETRY is the only visible action on the card in the verified sample.
  • The outer page still shows the Loopit chrome, views, likes, comments, and author line.
  • The verified route did not expose a recovery screen in our browser sample.

Controls

  • Tap the crash card or the TAP TO RETRY prompt.
  • Watch for any visible state change after the tap.
  • Treat the retry branch as unverified until the page visibly changes.

Strategy tips

  • Take the crash state as the starting point and only claim a recovery if the visible card changes.
  • Use the score text and heading as the simplest state check.
  • If retry does nothing, record the crash branch honestly instead of inventing a recovery.

Common mistakes

  • Assuming the retry tap succeeded when the card still says CRASHED.
  • Treating the static crash screen as a completed playable route.
  • Overstating recovery when the browser sample never leaves the crash state.
