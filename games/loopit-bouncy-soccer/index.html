Quick answer

Use the Play Bouncy Soccer button as the start point, then watch the live sequence rather than treating the page as a static card. The verified run used a 12-frame capture because the game is motion-driven.

How to play

  • The direct frame shows day/night art, a character switcher, a play button, and a chat box.
  • This is the dynamic entry in the run, so the evidence includes a short video plus key frames.
  • The page behaves like a live mini-game rather than a static gallery card.
  • The recorded frame sequence shows the game in motion; the still screenshots are just the published highlights.

Controls

  • Click Change Character to swap the on-screen character.
  • Click Play Bouncy Soccer to start the soccer sequence.
  • Use the chat box if you want to attach a short message to the share page.

Strategy tips

  • For documentation, keep the sequence short and honest: start, record, and pull two key frames from the motion clip.
  • Do not collapse the motion into a slideshow; the frame sequence is the real evidence here.
  • Use the dynamic video branch whenever the game is clearly alive and animated.

Common mistakes

  • Treating the dynamic soccer screen as a static screenshot-only page.
  • Skipping the frame-sequence capture and trying to fake motion with still images.
  • Ignoring the day/night art and control cluster, which are the visible affordances on the share frame.
