Quick answer

Tap Begin Session from Doctor Sigmunds Office to start the narrative. Treat it as a fictional game route, not real therapy or medical advice.

How to play

  • The source card asks, Trauma theory anyone?
  • The replay opened to Doctor Sigmunds Office.
  • The entry screen presents a calm session framing and a Begin Session button.
  • This is a game narrative; it should not be used as mental-health support.

Controls

  • Tap Begin Session to move from the office screen into the route.
  • Read prompts carefully because narrative games often branch through text choices.
  • Use screenshots if choices appear later, so branches are not mixed up.

Strategy tips

  • Start with the default Begin Session path and record the first few prompts.
  • If choices appear, map them as branches rather than assuming one correct answer.
  • Keep health or trauma-related wording framed as in-game fiction only.
  • Do not enter private personal information into a mini-game prompt.

Common mistakes

  • Treating the game as real mental-health advice.
  • Skipping text and losing the narrative branch context.
  • Publishing deeper branch claims without replay screenshots for those choices.
