Force Playground guide

Force Playground is a tool sandbox rather than a level route. Our replay verified the available powers and tool-selection prompt.

Play source game
Quick answer

Select one power, tap the screen, and observe the effect before switching tools. Start with Attract or Repel before using destructive tools like Explode or Hole.

How to play

  • Available tools include Attract, Repel, Explode, Hole, Laser, Zombie, and Reset.
  • The screen says to select a power and tap the screen.
  • Reset clears the experiment.
  • Our replay verified the tool panel, not a scored ending.

Controls

  • Tap a tool button to select it.
  • Tap inside the play area to apply the selected power.
  • Use Reset before testing a new setup.

Strategy tips

  • Start with Attract or Repel to learn object movement.
  • Use Explode and Hole after you understand the layout.
  • Keep one change per test so the result is readable.
  • Use Reset often; sandbox states can become messy.

Common mistakes

  • Switching tools too quickly to see effects.
  • Using Reset accidentally after a good setup.
  • Expecting a win screen from a sandbox.
