Pull the Pin guide

Pull the Pin is a drag-controlled physics puzzle with a safe lower pin and an upper lava hazard. Pulling only the lower-left red handle cleared the tested level.

Last updated July 16, 2026 · 1 tracked update

Play source game
Quick answer

Drag the lower-left red pin handle to the left and leave the upper lava pin in place; the verified run ends on LEVEL CLEARED.

How to play

  • The level presents multiple pins around a physics-based hazard layout.
  • The lower-left red handle is the safe pin used in the verified solution.
  • The upper pin contains the lava hazard and was left untouched.
  • One successful pull produced the LEVEL CLEARED screen with a Play Again button.

Controls

  • Press and drag the lower-left red pin handle toward the left.
  • Release after the pin has moved out of the chamber.
  • Use Play Again only after the LEVEL CLEARED result appears.

Strategy tips

  • Identify which pin releases the safe path before dragging anything.
  • Leave the upper lava pin in place so the hazard remains isolated.
  • Use a clean horizontal drag on the lower-left handle rather than tapping it.

Common mistakes

  • Pulling the upper lava pin before securing the safe route.
  • Tapping the pin without completing the drag gesture.
  • Claiming every level is solved when only the observed starting level was verified.
